# Documentation Index

This repository includes a set of focused documents. Each file has a single purpose so you can find the right information quickly.

## Core Documents

- `QUICK_START.md` — fast setup in 10-12 minutes.
- `GOOGLE_SHEETS_SETUP.md` — detailed Google Sheets form integration.
- `GOOGLE_SHEETS_QUICK_REF.md` — short reference for the setup steps.
- `SETUP_GUIDE.md` — high-level setup pointer to the Google Sheets guide.
- `MAINTENANCE.md` — customization, testing, and troubleshooting.
- `VISUAL_GUIDE.md` — visual layout, mobile views, and interaction details.
- `PROJECT_SUMMARY.md` — high-level summary of the project and changes.
- `IMPROVEMENTS.md` — design and technical improvements overview.
- `GOOGLE_SHEETS_UPDATE.md` — explanation of the switch to Google Sheets.
- `README_CHANGES.md` — brief change summary and pointers.

## Where to Start

1. `QUICK_START.md` — if you want to get the site working now.
2. `GOOGLE_SHEETS_SETUP.md` — if you need the full setup instructions.
3. `MAINTENANCE.md` — if you want to update content, colors, or forms.
4. `VISUAL_GUIDE.md` — if you want to understand the design and layout.
